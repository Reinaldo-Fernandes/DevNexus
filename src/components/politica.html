Política de Privacidade

Esta é uma versão simplificada, pensada pro estágio atual do projeto (protótipo, sem servidor próprio).

Onde seus dados ficam

Hoje o DevNexus guarda cadastro, projetos e vagas publicadas diretamente no navegador de quem está usando (via localStorage) — não existe um servidor central recebendo ou armazenando esses dados ainda. Isso significa que os dados ficam só nesse navegador/dispositivo e podem ser apagados a qualquer momento limpando os dados do site.

O que isso muda pra você

  • Seus dados não são compartilhados com terceiros nem enviados pra fora do seu navegador.
  • Se você trocar de navegador ou dispositivo, seu cadastro não vai junto.
  • Não há, por enquanto, criptografia de senha real — evite usar uma senha que você usa em outros lugares.

Conforme o projeto evoluir para ter um backend de verdade, esta política será atualizada pra refletir onde e como os dados passam a ser armazenados.
